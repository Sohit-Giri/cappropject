About RouteOptima

Nepal's shortest-path route optimizer — built with Dijkstra's algorithm and OpenStreetMap.
What is RouteOptima?

RouteOptima is a Final Year Project (FYP) built by Group 36 at IIMS College. It provides an optimized web-based interface to compute the shortest drivable route between any two geographic coordinates targeted across the Kathmandu urban ecosystem.

Real road network data is pulled directly from OpenStreetMap using the spatial computing framework osmnx and structured locally inside an indexed GraphML payload configuration. The localized pathfinder graph loads entirely into memory instances once, serving query lookups in micro-milliseconds.

The structural pathfinding algorithm handling calculating requests is Dijkstra's Shortest Path First (SPF) logic mapped through structural NetworkX nodes. Users can trace destinations across minor intersections or points of interest seamlessly without typing coordinates directly.
