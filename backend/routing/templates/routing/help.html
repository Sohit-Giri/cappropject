Help & FAQ

Common questions and troubleshooting tips.
Why is the map blank or stuck on "Loading graph"?
The backend framework loads the optimized topological data for Kathmandu District straight from OpenStreetMap on initialization. The layout status panel turns green when processing wraps up. Cached loads start instantaneously in milliseconds.
How does place search work?
We use the Nominatim geocoding API to parse open spatial databases. Type any place name — a tea shop, school, temple, bank — and matching entries populate inside a dynamic drop-down. Selecting a listing places the target pins.
Can I also click on the map instead of searching?
Yes. Click the "Click on map" activation button to switch input methods. Your next visual click on the viewport map plots either the structural origin or termination pin. The system cross-references structural components to output text coordinates automatically.
What spatial areas are covered?
The platform targets the structural boundary of Kathmandu District exclusively. The integrated road network configuration runs directly over 8,490 intersections/nodes and 21,519 calculated system edges.
How do I share a computed path?
After finishing a route execution process, choose the "Share" link generator button. A cryptographic secure URL maps to your system clipboard, permitting external view actions without an active authenticated session.
What is the Heatmap page?
It maps general density matrices showing popular start and terminal spatial intersections evaluated by application profiles. Brighter segments reveal dense node coordination requests.
How does the Leaderboard function?
It aggregates total shortest path distance metrics across registered users. Your cumulative route processing distances translate cleanly to your master index scorecard standing.
Can I alter the application system interface style?
Yes. Access theme modifications through user dashboard configurations or interact with color parameters found within the top landing navigation strip. Built-in variants include Midnight, Obsidian, Emerald, Crimson, Arctic, and Parchment.
